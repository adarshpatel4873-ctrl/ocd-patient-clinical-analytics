Project Objective

The objective is to explore the dataset and extract meaningful information through SQL queries. The analysis focuses on patient demographics, symptom patterns, diagnosis history, and Y-BOCS scores.

Dataset Information

The dataset contains patient age, gender, ethnicity, marital status, symptom duration, obsession and compulsion types, Y-BOCS scores, depression and anxiety diagnoses, and medication information.

Project Conclusion

This project demonstrates how SQL can be used to explore structured healthcare-related data, identify patterns, summarize patient information, and check data quality. It helped strengthen practical skills in MySQL and exploratory data analysis.
