01 / PROJECT INTRODUCTION

Project Overview

Objective

To explore healthcare-related patient data using MySQL and extract useful summaries about demographics, symptoms, diagnosis history, and Y-BOCS scores.

Dataset

The dataset includes age, gender, ethnicity, marital status, symptom duration, obsession and compulsion types, diagnosis fields and medication information.
